HP3 어드민 화면기획서 — 메뉴별 기능·정책 역분석 (AS-IS)

HP3_admin 소스 코드를 역분석해 메뉴·화면 단위로 정리한 화면기획서 2판입니다. 각 화면의 실제 캡처 이미지와 함께 정책·룰·세부 기능을 기술하며, 변수 시스템·부위(탭) 구조·컬러 모델 등 최신 반영 사항을 포함합니다.

0.1 메뉴 간 설정 관계 데이터 의존 · 선행 작업

어떤 메뉴의 설정이 어디에 영향을 주는지의 전체 지도. 새 기능 구성은 반드시 선행 메뉴 → 후행 메뉴 순서로 진행해야 한다.

① 브랜드 관리(브랜드·사용자 그룹) ──▶ ② 홈플래너 사용자(그룹 소속) ──▶ ③ 상품 편집 permission ──▶ ④ 설계 미리보기 "보는 사용자" 노출 필터

① 상품군·구분/견적그룹/모델/필드/필터 관리(마스터) ──▶ ② 상품 등록/편집(선택지 공급) ──▶ ③ 설계 라이브러리·견적

① 상품 관리(폴더·상품·DP·POS·변수) ──▶ ② 컨텐츠 그룹 관리(탭=부위, 교체 묶음·폴더 노출) ──▶ ③ 스타일 그룹 관리(부위 폴더 한 벌) + 상품 편집 구성/교체 연결 ──▶ ④ 설계 미리보기 스타일 설정(부위 타이틀 → 그룹 → 자동 부착/교체)

① APT 도면 관리(공개) ──▶ ② 홈플래너 아파트 검색·배치 ──▶ ③ 사용자 도면 관리(조회·렌더)

① 어드민 권한 관리(등급×메뉴) + 설정(메뉴·하위메뉴 표시) ──▶ ② 사이드바 노출 = 표시ON ∩ 등급 허용
설정하는 곳영향 받는 곳관계 설명

어드민 권한 관리사이드바 · 화면 접근등급의 menus에 없는 메뉴는 사이드바에서 숨김 + 진입 차단

상품 관리 폴더설계 라이브러리 · 컨텐츠 그룹노출 폴더 트리가 설계 라이브러리 구조 그대로. 비노출 폴더는 그룹으로만 노출. 숨김 폴더는 설계에서 제외
상품 변수(유형·노출)설계 속성 패널 · 도어 자동부착노출☑ 변수는 설계에서 조정 가능, W/D/H 수식=부착 치수, 조건식=배치 판정
컨텐츠 그룹 관리 탭스타일 설정 타이틀 · 구성/교체 행 · 스타일 그룹 부위탭 이름이 곧 부위 구분 — 세 화면이 같은 탭 목록을 공유

상품 편집 구성/교체설계 스타일 설정 배지부위별 연결 그룹이 '구성 슬롯' 배지·조건 분기의 기준
APT 도면 상태홈플래너 검색'공개'만 노출 — 검수중/임시저장은 미노출

2 사용자 관리

어드민/홈플래너 사용자는 동일 컴포넌트의 variant 분기. 브랜드·그룹 구조 편집은 브랜드 관리 전담.

2.1 홈플래너 사용자 관리 content-users

항목정책 / 룰 (2.1과의 차이)
대상콘텐츠 노출 대상 사용자(일반/B2B/VIP) — 로그인 주체 아님
핵심 기능사용자 그룹 소속 연결 — 상품 permission과 연동되어 설계 화면 노출 범위 결정
필수값이름만 필수. 권한 컬럼 없음, 브랜드는 그룹의 brandId에서 파생
그룹 일괄 설정체크 사용자에 그룹 팝오버로 지정 — 덮어쓰기(교체) 방식

사용 방법 — 노출 범위 구성 (브랜드 관리와 연동)

  • ① 브랜드 관리에서 브랜드·사용자 그룹을 먼저 생성 → ② 이 화면에서 사용자를 그룹에 소속 → ③ 상품 편집의 사용자 그룹(permission)에 같은 그룹 지정 → ④ 설계 미리보기 "보는 사용자"로 그 사용자를 선택하면 해당 상품만 보이는지 확인
  • 여러 명 한 번에 소속 변경: 체크 → [사용자 그룹 설정 ▾] → 그룹 체크(체크=소속, 해제=제거) → 저장 — 기존 소속을 교체하므로 유지할 그룹도 함께 체크

2.2 브랜드 관리 brands

항목정책 / 룰
역할브랜드·사용자 그룹 마스터 — 홈플래너 사용자 소속·상품 컨텐츠 권한과 공유
브랜드인라인 이름 편집(즉시 반영) · 동일 이름 추가 금지 · 삭제 시 하위 그룹 동반 삭제(계정은 유지, 소속만 해제)
그룹브랜드 셀 안에서 태그로 추가/이름변경/삭제. 그룹 삭제 시 사용자는 유지

사용 방법

  • 파트너사 신설: 하단 입력에 이름 → [브랜드 추가] → 소속 그룹 셀의 [+]로 그룹 추가(예: B2B 파트너) → [저장]
  • 이 화면의 그룹이 곧 홈플래너 사용자 소속·상품 permission의 선택지 — 노출 정책 단위로 그룹을 설계할 것 (예: 'VIP 고객' 그룹 = VIP 전용 상품 노출)

3 컨텐츠 관리

시스템 최대 복잡도 영역 — 상품(컨텐츠) 등록·분류·운영과 부위(탭) 기반 그룹/스타일 구성.

3.1 상품 관리 — 목록 / 폴더 트리 products

항목정책 / 룰
폴더 구조노출(설계 화면 노출)/비노출(부위 보관) 2섹션. 수납은 분류 폴더 — 하위 최종 폴더(몸통/도어/EP/상부·측면 서라운딩)에만 상품 배치, 직속 상품은 로드 시 품목 기준 자동 이관
폴더 기능드래그 재정렬(상단 ⅓=같은 레벨, 그 외=하위로) · 썸네일 지정/초기화(80px JPEG) · 설계 화면 숨김 토글 · 하위 있으면 삭제 불가(내부 상품은 상위로)
목록검색(이름·컨텐츠코드·상품코드, 폴더 무시 전체) · 속성 탭(배치형/설계형/텍스쳐/머터리얼) · 노출 스위치 인라인 · 복사(-COPY)/이동/삭제 · Undo/Redo(각 10, Ctrl+Z)
일괄 도구모델링 일괄등록(≤50, FBX→GLB 자동 변환·Draco) · 컨텐츠정보 엑셀(CSV) 다운로드/업로드(컨텐츠코드 매칭 일괄 수정)
썸네일생성 데이터는 종류 실루엣+모델 컬러+명칭 라벨 SVG 자동 생성(hp3gen). 업로드 이미지는 항상 우선
저장상품 CRUD는 즉시 영속화, 마스터 변경은 상단 저장으로 확정

사용 방법

  • 폴더 구성: 트리에서 상위 폴더 선택 → [+ 새 폴더] → 이름 입력. 폴더 ⋯ 메뉴로 썸네일/숨김/이름변경, 드래그로 순서·소속 이동(상단 ⅓=같은 레벨, 그 외=하위로)
  • 상품을 다른 폴더로: 체크 → 툴바 [폴더로 이동] select 또는 폴더 ⋯ 메뉴의 [선택 상품 이동/복사]
  • 대량 등록: [모델링 일괄등록] → 파일 선택(≤50) → 상품명 입력 → 등록(FBX는 GLB 자동 변환) / 속성 일괄 수정은 [컨텐츠정보 ▾] 다운로드 → 수정 → 업로드
  • 실수 복구: 삭제 직후 Ctrl+Z(최대 10회)

사용 방법 — 신규 상품 등록

  • 필드 의미가 궁금할 때: 라벨 옆 ⍰ 클릭 — #변수명과 사용 예시 확인
  • 사이즈 변형 라인 만들기: 같은 모델코드+품목코드로 W/H만 다른 상품 여러 개 등록 → 설계에서 해당 축이 단계 select로 전환

3.3 컨텐츠 운영정보 설계형 모델링 전용

블록정책 / 룰
운영 사이즈축별 MIN/MAX/GAP(mm) — 규격+GAP>1: 설계에서 단계 선택 / 비규격: MIN~MAX 자유 입력. 변수 #minW~#gapH(설정 축만)
변수 정의행 = 이름 + 유형(고정값/수식/조건식) + 값 + 노출☑. 이름 W/D/H의 '수식' 변수 = 내보내기 치수 · '조건식' 변수는 모두 TRUE일 때만 자동배치 · 노출☑ = 설계 화면 속성 패널에 표시/조정 가능(조정값이 수식 평가에 우선)
구성/교체부위(탭)별 고정 행 — 각 부위에 교체 묶음 또는 폴더 단위 노출 그룹을 연결/미연결. 연결된 부위만 조건 규칙(조건식→그룹 분기) 추가 가능. 기본 부위 상품 지정
스타일 그룹스타일 그룹 관리의 스타일을 토글 연결 — 선택 시 부위 일괄 교체 대상
DP/POS화면 입력 제거(정책) — 데이터는 유지, 수정은 컨텐츠정보 엑셀 경로

사용 방법 — 도어 자동부착 구성 (엔드투엔드)

  • ① 몸통 상품: DP 지정(엑셀 경로) + 변수 등록(예: LDH=20 고정값·노출☑)
  • ② 도어 상품들: 같은 DP + POS(L/R) + 변수 W(수식)=#bodyW/2-#body.패널두께, H(수식)=#bodyH-#body.LDH + 필요 시 조건식
  • ③ 컨텐츠 그룹 관리 도어 탭에 도어들을 교체 묶음(또는 폴더 단위 노출)으로 구성
  • ④ 몸통 편집의 구성/교체에서 도어 부위에 그 그룹 연결(+ 조건 규칙으로 분기 가능)
  • ⑤ 설계 미리보기에서 몸통 배치 → 스타일 설정 → 도어 그룹 → 리스트에서 선택 시 DP·POS·사이즈 맞춰 자동 부착. 노출 변수(LDH) 조정 후 재부착하면 치수 반영 확인

항목정책 / 룰

교체 묶음(좌)부위당 1개 — 폴더·개별 상품을 담아 교체 옵션 구성. 조건 분기 대상

사용 방법

  • 부위 추가: [+ 탭] → 이름(예: EP) — 설계 스타일 설정에 이 이름의 타이틀이 생김(그룹이 있어야 노출)
  • 교체 옵션 구성: 해당 탭에서 [+ 폴더 추가]/[+ 상품 추가]로 교체 묶음에 담기
  • 모델그룹 단위 노출: 우측 [+ 폴더 단위 노출 추가] → 그룹 생성 → 교체 묶음에 담긴 폴더 중 선택해 담기 — 설계에서 폴더 선택 시 DP·POS·사이즈 자동 매칭 부착
