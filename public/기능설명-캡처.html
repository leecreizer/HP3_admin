페이지별 기능 설명 — 화면 캡처 + 번호 주석

각 캡처의 빨간 번호 ●를 아래 설명 항목과 대조하세요. (프로토타입 localhost:5173 / 데이터 mock)

01 대시보드 02 도면 목록 03 도면 상세 04 사용자 관리 05 브랜드 관리 06 상품 리스트 07 상품 편집 08 상품군·구분 09 설정
01

대시보드

/dashboard
  1. 1좌측 사이드바 — 페이지 메뉴. 드래그 순서변경, 접기/펼치기. 권한별 노출(예정)
  2. 2상단바 — 검색·알림·로그인 사용자 정보. GET /auth/session
  3. 3리포트 내보내기 — 현재 기준 CSV/엑셀. GET /dashboard/report.csv
  4. 4KPI 4종 — 오늘 렌더·DAU·평균시간·실패율 + 증감. GET /dashboard/kpis
  5. 5렌더 처리 추이 — 최근 14일 완료/실패 라인. GET /dashboard/render-trend
  6. 6렌더 큐 — 처리중/대기/완료/실패 실시간. GET /renders/queue (폴링/WS)
  7. 7최근 완료 렌더 — 컬럼 정렬 테이블.
02

도면 관리 · 목록

/floorplans
  1. 1검색 — 단지명·평형·도면ID.
  2. 2상태 필터 탭 — 전체/공개/검수중/임시저장.
  3. 3정렬 — 최신수정/이름/평형 큰 순.
  4. 4도면 카드 — 썸네일 클릭 시 상세 진입.
  5. 5상태 배지 — public/review/draft.
  6. 6렌더 수 — 도면별 생성된 렌더 이미지 개수.
  7. 7도면 등록 미구현 — 업로드 모달 필요. POST /floorplans
03

도면 관리 · 상세

/floorplans/{id}
  1. 1목록으로 — 도면 목록 복귀.
  2. 2도면 메타 — ID·단지·평형·수정일·렌더수.
  3. 3공간 필터 탭 — 해당 도면 렌더의 room별 자동 구성.
  4. 4렌더 이미지 카드 — 스타일·생성일·소요시간. GET /floorplans/{id}/renders
  5. 5렌더 삭제 — DELETE /renders/{id}
  6. 6렌더 생성 미구현 — 비동기 큐 등록. POST /floorplans/{id}/renders

렌더 이미지는 반드시 선택한 도면에 종속되어 표시됩니다.

04

사용자 관리

/users
  1. 1요약 KPI — 전체/활성/휴면/차단.
  2. 2그룹 트리 — 브랜드>그룹 범위필터. 트리에서 그룹 추가·이름변경·삭제·드래그 이동. 브랜드 관리와 연동
  3. 3검색 — 이름·이메일·ID.
  4. 4상태 필터 — 전체/활성/휴면/차단.
  5. 5그룹 일괄 추가 — 선택 사용자 → 그룹. POST /groups/{id}/members
  6. 6사용자 테이블 — 전 컬럼 정렬 + 페이지네이션(브랜드/사번/조직/권한/그룹/가입·종료일/렌더/상태).
  7. 7행 수정·삭제 — 모달 편집.
  8. 8사용자 추가 — 필수: 이름·사번·조직 (이메일 선택). POST /users
05

브랜드 관리

/brands
  1. 1브랜드명 인라인 편집 — PUT /brands/{id}
  2. 2소속 그룹 태그 — × 로 그룹 삭제(사용자 소속만 해제).
  3. 3그룹 추가 — 브랜드 하위. POST /brands/{id}/groups
  4. 4브랜드 삭제 — 하위 그룹 cascade(confirm). DELETE /brands/{id}?cascade=true
  5. 5새 브랜드 추가 — 이름 유일성 보장. POST /brands

브랜드/그룹은 사용자 관리·상품 컨텐츠 권한과 동일 데이터로 연동됩니다.

06

상품 관리 · 리스트

/products
  1. 1상품 하위 메뉴 — 상품군·구분 / 모델 / 노출 필드 / 필터.
  2. 2폴더 트리 — 미분류 루트 고정. 펼침/접힘, 이름변경(✏️), 삭제(🗑️). 이동은 드래그&드롭만
  3. 3+ 새 폴더 — 선택 폴더 하위에 생성.
  4. 4검색 — 상품명·컨텐츠코드·상품코드.
  5. 5속성구분 탭 — 전체/배치형·설계형 모델링/텍스쳐/머터리얼(카운트).
  6. 6폴더 이동 — 선택 상품 일괄 이동.
  7. 7정렬 헤더 — 전 컬럼 정렬 + 페이지네이션(헤더 sticky 고정).
  8. 8노출 토글 — 인라인 노출여부. PATCH /products/{code}/visible
  9. 9행 수정·삭제 — 편집화면 진입 / 삭제.
  10. 10상품 등록 — 등록 모달(기본정보=편집과 동일). POST /products
07

상품 관리 · 편집 화면

3패널
  1. 1썸네일 · 에셋 — 400×400 썸네일 업로드 + 에셋(확장자 자동인식, three.js 미리보기). AssetBundle은 서버 glTF 변환 필요
  2. 2기본 정보 — 상품명·브랜드·견적그룹·상품군·상품구분(군 종속)·코드·권한·노출·속성구분·크기·배치위치/높이·스펙/mall URL·필터.
  3. 3컨텐츠 운영 정보 — 상품군+상품구분 조합별 항목. 조합 매핑 미정(발주처 제공 예정)
  4. 4나가기 — 저장 전 변경(에셋·썸네일 포함) 전부 원복.
  5. 5저장 — PUT /products/{contentCode}
08

상품 관리 · 상품군·구분 관리

/products/catalog
  1. 1관리 모달 — 상품군 + 상품구분(품목) 통합 관리.
  2. 2상품군 추가 — POST /product-groups
  3. 3상품군명 편집 — 변경 시 관련 상품 동기화.
  4. 4상품구분 칩 — 품목 추가/이름변경/삭제. 필터의 ‘상품 구분’ 파생목록과 연동.

모델 관리·노출 필드 관리·필터 관리도 같은 패턴(목록 + 추가/수정/삭제 + 저장). 필터의 ‘상품/모델 구분’은 읽기전용.

09

설정

/settings
  1. 1메뉴 순서 — ▲▼ 이동(사이드바 드래그와 동일).
  2. 2메뉴 이름 — 인라인 변경.
  3. 3표시 토글 — 메뉴 노출 on/off.
  4. 4메뉴 추가 — 커스텀 메뉴(준비중 페이지 연결).
  5. 5상품관리 하위메뉴 관리 — 순서·이름·표시(키 고정).
  6. 6상부 메뉴 관리 — 브랜드명/부제·검색창·알림·관리자 정보.
  7. 7기본값으로 되돌리기 — DEFAULT_CONFIG 복원.

현재 localStorage 저장 → 실제로는 조직/관리자 단위 서버 저장 + 권한별 기본값 필요. GET/PUT /admin/config
