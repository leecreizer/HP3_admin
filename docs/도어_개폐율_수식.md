# 도어 개폐율(#DROP) 수식 정리

도어 개폐율 `#DROP`(0~100)에 따라 여닫이 도어를 열고 닫는 설계변수 수식.
개폐율 100 = 90° 완전 개방. 도어 지오메트리의 **피벗은 왼쪽 엣지에 고정**(이동 불가)을 전제로 한다.

## 파라미터

| 이름 | 의미 |
|---|---|
| `#DROP` | 개폐율 (0~100) |
| `#DRW_GAP` | 도어-몸통 갭 |
| `#DBD` | 도어 두께(깊이 오프셋 기준) |
| `#DR_W` | 도어 폭 |
| `#UNIT_W` | 도어가 붙는 유닛/칸 폭 (시스템 실제 파라미터명으로 치환) |

## 왼쪽 힌지 도어 (피벗 = 힌지, 기준 구현)

```
Position X => #DRW_GAP + #DROP/3*1.5
Position Y => #DROP==100 ? 0-100 : -#DBD-10
Rotate   Z => -(#DROP*3.6)/4
```

- Rotate Z: 1%당 −0.9°, 100%에서 −90°
- Position X의 `+#DROP/3*1.5`(1%당 +0.5): 피벗-힌지 미세 편차 보정(경험 보정치)
- Position Y: 힌지가 놓이는 깊이 위치. 개방 중 `-#DBD-10`, 완전 개방 시 `-100`

## 오른쪽 힌지 도어 (피벗은 왼쪽 엣지 = 자유단)

힌지는 도어 오른쪽 엣지인데 회전 피벗은 왼쪽 엣지이므로,
회전 후에도 오른쪽 엣지(힌지)가 제자리에 있도록 피벗을 이동시키는 보정이 필요하다.

θ = `(#DROP*3.6)/4` (도 단위, 100%에서 90°)

```
Rotate   Z => (#DROP*3.6)/4                              // 좌측의 부호 반전
Position X => #UNIT_W - #DRW_GAP - #DR_W + #DR_W*(1-cos((#DROP*3.6)/4))
Position Y => (#DROP==100 ? 0-100 : -#DBD-10) - #DR_W*sin((#DROP*3.6)/4)
```

### 유도

- **X**: 닫힘 기본 위치 X0 = `#UNIT_W - #DRW_GAP - #DR_W`
  (오른쪽 끝에서 갭만큼 안쪽, 피벗은 도어 왼쪽 엣지이므로 도어폭만큼 왼쪽).
  회전 시 힌지 고정 조건에서 피벗 X = X0 + `#DR_W×(1−cosθ)` → 0%에서 0, 100%에서 +도어폭.
- **Y**: 삼항식 부분은 좌측 도어와 동일한 "힌지의 깊이 위치".
  피벗(자유단)은 힌지를 중심으로 호를 그리며 앞(−Y)으로 나오므로 `−#DR_W×sinθ` 보정.
  - 0%: 보정 0 / 50%: −0.707×도어폭 / 100%: −도어폭
- **검산 (100% 개방)**: 우측 피벗 Y = −100−#DR_W, 힌지 = 피벗 + #DR_W×sin90° = −100
  → 좌측 도어의 100% 힌지 깊이(−100)와 일치, 좌우 대칭 성립.

### 삼각함수 미지원 시 다항 근사

```
Position X => #UNIT_W - #DRW_GAP - #DR_W + #DR_W*#DROP*#DROP/10000
Position Y => (#DROP==100 ? 0-100 : -#DBD-10) - #DR_W*#DROP*(200-#DROP)/10000
```

- X 근사: 0%/100% 정확, 50%에서 약 −4% 오차
- Y 근사: 0%/100% 정확, 50%에서 약 +6% 오차

## 알려진 이슈

- 삼항식 특성상 99%→100% 구간에서 Y 베이스가 `-#DBD-10` → `-100`으로 점프.
  개폐율을 연속 애니메이션하면 좌우 도어 모두 마지막에 살짝 튐 —
  부드럽게 하려면 좌·우 도어 모두 삼항식을 연속식으로 교체 필요 (좌측과 함께 조정할 것).
