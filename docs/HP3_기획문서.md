## 1. 개요

HomePlanner3 Admin은 인테리어 콘텐츠(상품·모델링)를 등록·관리하고, 사용자 그룹별 권한으로 노출을 제어하며, **설계 미리보기**에서 three.js 웹플래너(별도 앱)에 상품/모델을 배치·자동조립·견적 확인하는 운영 도구다.

- **프론트엔드**: Vite + React 19 + TypeScript (`c:\workspace\HP3_admin`)
- **설계 캔버스**: R3F(three.js) 웹플래너 (`d:\unity\homeplanner3-web`), 어드민에 iframe 임베드
- **연동**: `postMessage` (어드민 5180 ↔ 웹플래너 5190)
- **영속화**: localStorage(메타·설정) + IndexedDB(에셋 바이너리)
- **인증**: 별도 백엔드 없음 — 로그인 사용자는 사용자 관리 목록에서 선택(전환)

   localStorage: 상품/폴더/그룹/사용자/브랜드/설정 (메타)

## 3. 로그인 / 사용자 연동

- 로그인 사용자 = **사용자 관리에 등록된 사용자 중 선택**. 상단바 드롭다운으로 전환하며 `hp3-login-user`에 보존.
- 기본값: 로그인 계정 이메일(`config.topbar.userAccount`)과 일치하는 사용자, 없으면 첫 사용자.
- 로그인 사용자 정보가 반영되는 곳:
  - 상단바 이름·등급·이메일
  - 상품 등록/수정의 **최종수정자**(updatedBy)
  - 관리자 여부(최고관리자/운영자) → 설계 미리보기 "전체 열람" 가능
  - 설계 미리보기 기본 "보는 사용자"
- 시드에 이대우(leedw0341@hanssem.com, 최고관리자) 포함.

## 4. 사용자 관리

- 목록: 이름/이메일/사번/소속/권한/가입·종료일/최근접속/렌더수/상태.
- **권한** 컬럼: 권한 관리(운영자 등급, scope=admin)에 등록된 값만 노출. 등급에 없는 값은 `–` 표시.
- **사용자 그룹**(명칭 통일): 사용자별 복수 소속(`groupIds`). 브랜드 관리와 공유되는 그룹 마스터 사용.
- 일괄 작업:
  - **전체선택 / 선택취소** 버튼
  - **사용자 그룹 설정**(체크박스 팝오버): 체크된 사용자들의 그룹을 **선택 상태로 저장**(체크=소속, 해제=제거). 팝오버 열면 기존 소속이 미리 체크됨. 그룹 목록 **전체선택/선택취소** 지원.
- 최상위 그룹(브랜드) 추가는 **브랜드 관리**에서만. 사용자 관리에선 그룹 소속만 편집.
- 저장 버튼으로 영속화.

## 7. 상품 관리

### 7.1 폴더 패널 (좌측)
- 노출(`external`)/비노출(`internal`) 2섹션, 트리 구조.
- **카테고리 설정 바**: 상단 sticky 고정(스크롤해도 유지, 불투명 배경으로 내용 가림). `+ 새 폴더`로 선택 폴더 하위에 생성.
- 폴더 이름변경/삭제. (스크롤 시 자동 닫힘 기능은 제거됨)
- 폴더 대표 썸네일: 직접 담긴 콘텐츠 기준, 없으면 folder.png.

### 7.2 상품 목록 (우측)
- 검색/정렬/필터(배치형·설계형·텍스쳐·머터리얼).
- 행 액션: 수정 / 삭제.
- 헤더 액션: **+ 상품 등록**, **복사**(체크 N개 일괄 복제 — 기본정보·운영정보 전체 복사, 컨텐츠코드만 `원본-COPY`로 새로 부여), **저장**.

### 7.3 상품 기본 정보 (편집/등록 폼)
- 상품명, 브랜드, 상품군, 견적그룹, 상품 구분(상품군별), 모델 구분(상품군별).
- 코드 2×2 블록: **컨텐츠 코드 · 상품코드 / 모델코드 · 품목코드** (노출 필드 관리의 `editable`에 따라 수정 가능/불가).
- **사용자 그룹**(구 "컨텐츠 권한"): 전체 또는 특정 사용자 그룹 → 이 그룹 사용자에게 노출.
- 가격.
- **규격유무**(라디오: 규격/비규격, 기본 규격) + **노출여부**(토글) 같은 줄.
- 속성 구분: 모델링(배치형/설계형) / 텍스쳐 / 머터리얼.
- 컨텐츠 크기(W/D/H), 배치 위치, 배치 높이.
- 스펙 URL / mall URL (복수).
- 필터(필터 관리 옵션).
- 썸네일 이미지 + **업로드 에셋**(미리보기 항상 표시, 업로드→**등록/취소**, 3D 미리보기 glb/gltf/obj/fbx + 환경맵).

### 7.4 컨텐츠 운영정보 (**설계형 모델링에서만** 노출)
- **운영 사이즈 / 비규격 사이즈**(비규격 체크 시 명칭 변경): 축별 MIN/MAX/GAP.
  - MAX>MIN & GAP>1 → 단계 드롭다운, GAP=1/미설정+범위 → 직접 입력(범위 클램프), MIN만/MIN=MAX → 고정, 미설정 → 자유 입력.
- **변수 정의**: 수식에서 `#이름`으로 참조할 사용자 변수(이름+값/식). 기본 변수 `#W #D #H`(자기), `#bodyW #bodyD #bodyH`(몸통).
- **내보내기 수식**(W/D/H) + **조건식**(TRUE일 때만 자동배치). → 수식 엔진(§11).
- **운영 항목**: 상품군·상품구분 조합별 항목(OPERATION_SPEC, 일부 정의).
- **구성/교체(모델링 그룹)**: 조립형 상품의 부위 슬롯에 모델 그룹 연결.

### 7.5 DP · POS (**모델링 도어/EP 컨텐츠에 노출, 배치형·설계형 무관**)
- 노출 규칙: 상품구분 이름에 **"도어" 포함 → DP+POS**, **"EP" 포함 → POS만**, 그 외(장·서라운딩 등) → 숨김. 상품구분 변경에 즉시 반응.
- **DP** = 도어 형태 + 붙는 위치(몸통↔도어 매칭 키).
- **POS** = 열림 방향(L/R 등, 부착 위치 구분).
- ⚠ 현재 한계: 노출 판정이 **상품구분 이름 매칭**이라, 수납처럼 도어 역할 구분명에 "도어"가 없으면(예: 스윙장) 안 뜸. → §13 추후(상품구분별 DP/POS 지정).

### 7.6 노출 필드 관리
- 필드별 수정가능(editable)·필수 등 정의. 컨텐츠 코드/상품코드의 폼 수정 가능 여부를 제어.

### 7.7 상품군·구분 / 견적그룹 / 모델 구분 / 필터 관리
- 각 마스터 추가·수정·삭제. 상품구분·모델구분은 상품군별.

## 8. 그룹 관리 (모델 그룹)

> 여러 모델링(폴더/상품)을 하나의 **모델 그룹**으로 묶어, 설계에서 부위 교체·자동조립에 사용.

- 카테고리 탭(몸통/도어/손잡이 …) 추가·이름변경·삭제(확인).
- 탭 내 **모델 그룹** 생성·이름변경·삭제.
- 그룹 멤버 구성(둘 다 가능):
  - **+ 폴더 추가**: 상품관리 폴더(모델 분류) 연결. 폴더 하위 상품이 멤버에 포함.
    - 연결 폴더마다 **상품화 체크박스**: 체크 시 그 폴더를 "단일 자동조립 단위(상품화)"로 취급(설계 표현용), 해제 시 일반(내부 상품 개별). 그룹별로 따로 저장(`folderModes`).
  - **+ 상품 추가**: 개별 상품을 이름·코드 검색으로 직접 추가(`📦` 태그).
- 멤버 해석(`expandMembers`): **폴더 하위 상품 ∪ 직접추가 상품** (중복 제거).
- **스타일 탭**: 여러 폴더(모델)를 묶은 상위 스타일 + 대표 썸네일.
- 저장 버튼으로 영속화(기존 저장본 보존, `folderModes`/`items` 없으면 빈 값).

## 9. 설계 미리보기 (핵심)

좌: 상품 라이브러리 / 중: 웹플래너 캔버스(iframe) / 우: 상품·공간 정보.

### 9.1 상품 라이브러리
- stg 홈플래너 구조: 영역(설계형/배치형/재질형) → 하위 폴더 → 상품(드릴인, 브레드크럼).
- 폴더 타일/상품 타일. 폴더 대표 썸네일.
- **상품화 폴더**(asProduct 플래그가 켜진 폴더)는 상품 타일처럼 노출(드릴인 X) — 클릭 시 선택 몸통에 DP 자동 부착. (참고: 상품화는 그룹의 폴더모드로 이전됨 — §13)

### 9.2 노출 필터 (권한/그룹/노출여부)
- **노출여부(visible=false)**: 권한과 무관하게 **항상 제외**.
- **사용자 그룹(permission)**: `전체` 공개 + **보는 사용자의 소속 그룹과 일치**하는 콘텐츠만.
- **보는 사용자** 선택기: 기본 로그인 사용자, 관리자면 "전체(관리자)"로 모두 열람, 임의 사용자 시점 시뮬레이션.

### 9.3 우측 패널 — 상품 정보 / 공간 정보
- 미선택 시: **공간 정보**(바닥 폭/깊이 10000mm, 면적 100㎡, 배치 상품 수, 배경 흰색).
- 선택 시 타이틀 **"상품 정보"** 고정(탭 명칭과 무관).
- 탭: **속성설정 / 스타일 설정**.
- **속성설정**: W/D/H + 배치높이(0도 표기, 기본값=상품 placeHeight) + 스펙파일/URL(기본정보 specUrls/mallUrls에서) + 가격.
  - 사이즈 입력 방식 우선순위: ① 모델+품목 형제(아래) ② 운영 사이즈(opSize) ③ 자유 입력.
  - **모델+품목 코드 형제**: 모델코드·품목코드가 모두 같은 상품들 = 사이즈 변형 라인. 축별 값이 여럿이면 드롭다운, 하나면 고정. 다른 값 선택 시 **하나의 컨텐츠가 그 자리에서 형상 변형 + 코드 교체**(새 배치 아님).
  - 운영 사이즈 마우스오버 시 가능 값/범위 안내(ⓘ).
- **스타일 설정**:
  - 조립형(modelingSlots): 구성 그룹 클릭 → **DP 매칭 도어 자동 배치**(§10).
  - 단일형: 상품교체 플라이아웃(폴더 목록 → 드릴 → 교체), 검색·필터(드래그 가능 팝업).

### 9.4 견적보기
- 상단 **견적보기(N)** → 큰 모달(96vw)로 배치 내역 표: 명칭/상품코드/모델코드/품목코드/컨텐츠코드/사이즈(W×D×H). 닫기 우상단.
- 배치 목록은 웹플래너가 `hp3:scene`로 전송 → 어드민이 상품코드로 매핑.

## 10. DP 매칭 자동 배치 (도어 부착) — 시뮬레이션

```
몸통 배치 → 선택 → 스타일설정 → 구성 그룹(또는 상품화 폴더) 선택
  후보 = 그룹/폴더의 멤버 도어 (contentCode)
  매칭 = 도어.DP == 몸통.DP
  조건식 = 도어 condition (TRUE인 것만)
  사이즈 = 도어 수식(W/D/H) 계산값, 없으면 기본값
  배치 = 도어.POS(L/R)에 따라 몸통 좌/우 위치(현재 폭 기준 자동)
```
- 어드민이 `hp3:attach-doors`로 도어 목록 전송 → 웹플래너가 선택 몸통 기준 좌/우에 박스/모델로 배치.
- 결과/오류 배너 표시(몸통 미선택·DP 없음·매칭 없음·조건 미충족).

## 11. 수식 엔진 (쿠지알러 스타일)

- 함수: `evalFormula(expr, vars)` — eval 미사용 안전 파서. 결과 number 또는 boolean.
- 지원:
  - 변수 `#이름` 또는 `이름` (# 유무 무관)
  - 산술 `+ - * / ( )`, 소수
  - 비교 `>= <= > < == !=`, 논리 `AND OR NOT`(또는 `&& || !`)
  - 함수 `sin cos tan asin acos atan toRadians toDegrees sqrt abs round floor ceil min max pow`, `if(cond,a,b)`, 상수 `PI`
- 활용: 도어 내보내기 사이즈(W/D/H), 조건식(자동배치 노출 조건), 사용자 정의 변수 값.

## 12. 웹플래너 연동 (postMessage)

| 메시지 | 방향 | 내용 |
|---|---|---|
| `hp3:place-product` | 어드민→웹 | 신규 배치(고스트→클릭 배치). name/code/modelUrl/w/d/h/lift |
| `hp3:update-product` | 어드민→웹 | 선택(없으면 마지막) 배치 컨텐츠를 그 자리에서 수정(치수/코드/모델) |
| `hp3:swap-product` | 어드민→웹 | 선택 박스 교체 |
| `hp3:attach-doors` | 어드민→웹 | 선택 몸통에 DP 매칭 도어들 POS(좌/우) 자동 배치 |
| `hp3:selected` | 웹→어드민 | 박스 선택 → 상품 정보 동기화(code, 다중 시 count) |
| `hp3:deselected` | 웹→어드민 | 빈 곳 클릭 해제 → 공간 정보 복귀 |
| `hp3:scene` | 웹→어드민 | 배치 목록/개수(견적보기·공간정보) |

### 웹플래너 캔버스 동작
- 흰색 배경 + 바닥 플랜(크기 10), AO off.
- 배치 박스: 모델 등록 시 GLB 렌더(없으면 박스 폴백). 모델은 W/D/H에 맞춰 스케일·바닥 정렬.
- 선택: 클릭=단일, **Shift+클릭=다중**. 선택 박스들의 **중심 피벗 기즈모**로 이동(X/Z)·회전(Y). 빈 곳 클릭 시 해제(`onPointerMissed`, 기즈모 클릭은 제외).
- 배치 대기(고스트)에도 등록 모델 미리 표시.

## 13. 모델링(에셋) 저장 — IndexedDB

- 에셋 업로드는 **data URL(base64)** 로 읽어 교차출처(iframe) 로드 가능.
- 큰 GLB는 localStorage 용량(~5MB) 초과 → **IndexedDB(`hp3-assets`)에 바이너리 저장**, localStorage엔 메타(id/name/type)만.
- 로드 시 IDB에서 url 하이드레이트: 상품 편집 미리보기(AssetViewer), 설계 배치(modelUrl 맵).
- ⚠ 기존(수정 전) 등록 모델은 url이 빠져 있을 수 있음 → **재등록(에셋 업로드→등록→상품 저장)** 필요.

## 15. 미구현 / 추후 과제

1. **상품구분별 DP/POS 지정** — 현재 이름 매칭("도어"/"EP")의 한계 해소. 상품군·구분 관리에서 구분마다 DP/POS 사용 여부를 직접 지정(권장).
2. **그룹 폴더모드(상품화)의 설계 반영** — 📦 상품화 폴더 = 단일 자동조립 타일, 📁 일반 = 내부 상품 개별. 설계 라이브러리/플라이아웃 표현 연결.
3. **POS 정밀 좌표** — 현재 좌/우는 몸통 폭 기준 자동. 실제 모델 메타(부착 지점) 연동.
4. **실 서버 업로드 API** — IndexedDB 시뮬레이션을 실제 에셋 스토리지/CDN URL로 교체.
5. **견적 로직** — 견적보기는 내역 표시 단계. 견적그룹 기반 가격 산출 연동.
6. **로그인 인증** — 현재 사용자 전환 방식 → 실제 인증/세션.

## 16. 핵심 정책 요약

- **노출 = 노출여부(항상) ∩ 사용자 그룹(권한)**. 관리자(전체)는 그룹 무시 열람.
- **운영정보(사이즈/변수/수식/구성)** 는 설계형 모델링에만. **DP/POS** 는 도어/EP 모델링이면 배치형·설계형 무관.
- **그룹** = 폴더 + 개별상품 묶음. 폴더는 그룹 안에서 상품화/일반 모드 지정.
- **자동조립** = 몸통 DP ↔ 도어 DP 매칭, POS로 좌/우, 수식/조건 적용.
- **모델 배치** = 등록 GLB가 있으면 모델, 없으면 박스. 바이너리는 IndexedDB.
