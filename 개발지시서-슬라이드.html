Common · 01

공통 사양

레이아웃 셸

  • 좌 사이드바(266/104px) · 상단바(72px) · 메인(1fr), 높이 100vh 고정
  • 상단바·사이드바 고정, 리스트는 툴바·테이블 헤더 sticky + 내부 스크롤

디자인 시스템 · 공통 컴포넌트

  • CSS 변수 팔레트 + Pretendard / Space Grotesk(숫자)
  • Pagination(20/50/100) · useSort/ThSort · AssetViewer(three.js)
  • 상태 영속화는 현재 localStorage → 실제 API+DB로 교체
Page · 02

대시보드 /dashboard

화면

  • KPI 4종(오늘 렌더·DAU·평균시간·실패율)
  • 렌더 처리 추이(14일) · 렌더 큐
  • 최근 완료 렌더 테이블(정렬)

기능 · API

  • GET /dashboard/kpis 증감 포함
  • /render-trend · /renders/queue
  • 큐 10초 폴링 or WebSocket
  • 리포트 내보내기(CSV)

실패율 = fail/(done+fail) 당일 누계 · 평균시간은 성공 건만.

Page · 03

도면 관리 /floorplans

기능

  • 목록: 검색·상태탭·정렬·카드 그리드
  • 도면별 렌더 이미지 갤러리(공간 탭)
  • 렌더 삭제 / 도면·렌더 생성 미구현

모델 · API

  • Floorplan 1—N RenderImage
  • GET /floorplans/{id}/renders?room=
  • POST .../renders → 비동기 큐

렌더 이미지는 반드시 해당 도면에 종속. 상태 public·review·draft.

Page · 04

사용자 관리 /users

기능

  • 좌 그룹 트리(브랜드>그룹) 범위 필터
  • 검색·상태필터·전컬럼 정렬·페이지네이션
  • 추가/수정 모달 · 일괄 삭제 · 그룹 일괄 추가
  • 그룹 추가·이름변경·삭제·드래그 이동

규칙

  • 필수: 이름·사번·조직 (이메일 선택)
  • User ↔ Group N:M, 브랜드는 그룹에서 도출
  • 그룹/브랜드 변경 = 브랜드 관리와 연동
  • 그룹 삭제 → 사용자 유지·소속만 해제
Page · 05

브랜드 관리 /brands

  • 브랜드(파트너사) 추가·인라인 수정·삭제, 그룹 추가·삭제
  • 브랜드 삭제 시 하위 그룹 cascade + 사용자 소속 자동 해제(confirm)
  • 브랜드명 유일성 보장
  • 사용자 관리 그룹 · 상품 컨텐츠 권한과 동일 데이터 연동

API: GET/POST/PUT/DELETE /brands, DELETE ?cascade=true, /brands/{id}/groups

Page · 06a

상품 — 폴더 & 리스트

폴더 트리

  • 미분류 루트 고정(삭제·이동·이름변경 불가)
  • +새폴더 = 선택 폴더 하위 생성
  • 이동은 드래그&드롭만(앞/하위)
  • 삭제 시 상품은 상위로, 하위폴더 있으면 차단

리스트

  • 검색·속성구분 탭·폴더필터·정렬
  • 노출 토글 · 폴더 일괄 이동 · 삭제
  • 컬럼: 상품명·브랜드·상품군·모델·품목·견적·코드·노출·배치·사이즈·속성
Page · 06b

상품 — 등록 / 편집

기본정보(등록·편집 동일)

상품명브랜드견적그룹 상품군상품구분(군 종속)컨텐츠코드 상품코드컨텐츠권한(그룹)노출 속성구분크기배치위치·높이 스펙URLmallURL필터

  • 3패널: 썸네일·에셋 / 기본정보 / 운영정보, 나가기 시 원복
  • 에셋 확장자 자동인식 + three.js 미리보기
  • AssetBundle은 서버 glTF 변환 필요 · 운영정보 조합 매핑 미정
Page · 06c

상품 — 하위 메뉴 4종

  • 상품군·구분 관리 — 상품군 + 품목(구분) 추가/이름변경/삭제, 상품 동기화
  • 모델 관리 — 상품군별 모델(시리즈) 관리
  • 노출 필드 관리 — DB 필드 정의(현재값=기본세팅) + 저장 · builtin 삭제불가
  • 필터 관리 — 그룹+옵션 2단. ‘상품 구분·모델 구분’은 읽기전용(각 메뉴에서만 수정)

상품군·모델·필터는 서로 파생·연동되는 단일 출처로 관리.

Page · 07

설정 /settings

  • 좌측 메뉴 관리 — 순서·이름·표시·추가·삭제(사이드바 드래그와 동일 데이터)
  • 상품관리 하위메뉴 — 순서·이름변경·표시(키 고정)
  • 상부 메뉴 — 브랜드명/부제·검색창·알림·관리자 정보
  • 삭제한 기본 메뉴는 removedMenus로 부활 방지

실제로는 조직/관리자 단위 서버 저장 + 권한별 기본값.
